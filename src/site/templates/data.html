Keep a spreadsheet up to date

  1. Right-click a CSV link below and copy the link address.
  2. In Excel: Data → From Web, paste the link, then Load.
  3. Later, Data → Refresh All pulls the latest figures.

Addresses look like …/data/series/ICSA.csv and never change. Each XLSX has an About sheet with the source, units and citation; DOL files also have a Columns sheet describing every column.
